## r6 Candidate

r5 added the explicit `real_chrome` surface and proved live delivery against a
visible ordinary Chrome. Unattended/windowless macOS sessions cannot satisfy
Chrome's mandatory per-connection approval dialog, and cold writes using the
legacy PP-CLI SQLite format are rejected by Chrome 149. The r6 candidate solves
the actual unattended case with a separate offline mode: stop only when Chrome
was running, write `SHA256(host_key) || value` while preserving schema version
24, then restore the prior running state. It also replaces content-hash-only
ad-hoc signatures with the stable identifier and designated requirement
`io.github.yoyooyooo.agentcookie`.

The implementation delta is `7d09916ee8719f5bc9b17cf3cc22047528991331`
plus portability fix `c53fede`; the final candidate also includes this
classification record. No r6 artifact or deployment is claimed until the
exact final SHA passes hosted CI and the immutable release workflow publishes
consumer-verifiable assets.
