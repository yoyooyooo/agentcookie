## r7 Release Acceptance

r7 is the accepted ordinary-Chrome generation. It contains r6's unattended
offline host-bound delivery, automatic prior-state restoration, live-endpoint
disable command, and stable Darwin application identity. Its bundled Skill now
distinguishes ordinary Chrome, externally managed automation Chrome, and named
Agent Browser sessions; OpenCLI/OpenClaw are control layers over ordinary Chrome,
not separate Cookie Stores.

The immutable tag peels to exact source
`35e9301d27cbb363f60e5d33fe82e59b8c517f3f`; hosted checks and release run are
recorded above. This post-tag evidence does not alter that source.
