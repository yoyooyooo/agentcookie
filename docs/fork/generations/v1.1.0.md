## r7 Candidate

r6 is the first unattended ordinary-Chrome release: it includes offline
host-bound writes, automatic prior-state restoration, a disabled live endpoint
when no longer needed, and one stable Darwin signing identity. The r7 candidate
aligns the bundled Skill with that implementation. It tells agents to distinguish
ordinary Chrome, externally managed automation Chrome, and named Agent Browser
sessions; OpenCLI/OpenClaw are described as control layers over ordinary Chrome,
not separate Cookie Stores.

The Skill delta is `6a9f8d4`; the final candidate also includes this
classification record. No r7 artifact or deployment is claimed until the exact
final SHA passes hosted CI and the immutable release workflow publishes
consumer-verifiable assets.
